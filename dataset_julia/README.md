# Генератор синтетичного датасета для GNN + GRU

## Запуск

```bash
pip install numpy
python generate_grain_dataset.py --scenarios 500 --out grain_dataset --seed 42
```

Швидка перевірка:

```bash
python generate_grain_dataset.py --scenarios 12 --out test_dataset
```

Програма використовує лише NumPy. За замовчуванням: три засіки, 48 годин, крок чисельного інтегрування 60 секунд, запис кожні 15 хвилин, історія для мережі 48 точок (12 годин), зсув вікна 4 точки (1 година). У середньому засіку випадково змінюється температура вентиляційного повітря через 6–24 години від початку сценарію.

## Файли

- `trajectories.npy` — масив `(кількість_сценаріїв, 193, 3, 11)`.
- `edge_index.npy` — орієнтовані ребра графа 1 ↔ 2 ↔ 3 (індекси 0, 1, 2).
- `edge_weight_W_per_K.npy` — постійне припущене значення 0,026 Вт/К для кожного ребра.
- `scenarios.jsonl` — параметри кожного сценарію, включно з масами, густинами, об'ємами й моментом зміни вентиляції.
- `train_windows.csv`, `val_windows.csv`, `test_windows.csv` — індекси навчальних прикладів, розділені **за сценаріями**, щоб не змішувати майже ідентичні вікна між наборами.
- `manifest.json` — порядок 11 вхідних ознак, форма вікон, усі припущення та кількості прикладів.

## Один приклад для GNN + GRU

Читаємо один рядок з `train_windows.csv`. За його `scenario_id` і `start_frame` беремо 48 часових станів усіх трьох засіків:

```python
import numpy as np
X = np.load('grain_dataset/trajectories.npy', mmap_mode='r')
edge_index = np.load('grain_dataset/edge_index.npy')
sid, start, last, target = 0, 0, 47, 48  # лише приклад, справжні індекси — з CSV
x = X[sid, start:last + 1]   # (48, 3, 11)
y = X[sid, target, :, 0] - X[sid, last, :, 0]  # (3,), прогнозована зміна T
print(x.shape, y.shape)
```

Під час навчання нормалізуйте вхідні числові ознаки **лише за train-сценаріями**; для п'яти бінарних ознак виду зерна нормалізація не потрібна. Для прогнозування після моменту зміни вентиляції слід забезпечити, щоб її поточне значення було відоме на момент прогнозу.

## Наукові обмеження

Це **прототип для попереднього навчання на синтетичних даних**, не фізично верифікований цифровий двійник. У вихідній формулі невідомі числові параметри теплообміну, самозігрівання і вологопереносу. Тому в програмі явно прийнято припущення: ефективність вентиляційного теплообміну 0,2; теплообмін із приміщенням 2 Вт/(м²·К); площа поверхні 1,5·V^(2/3); умовний закон самозігрівання; умовний закон зміни вологості при постійній відносній вологості повітря 60%. **Ці коефіцієнти не можна називати експериментально встановленими.**

Наведене значення K=0,026 Вт/К стосується лише теплопровідності через нерухоме повітря (1 м, 1 м²), не враховує конвекцію чи випромінювання. Через те що зв'язок дуже слабкий, у такому датасеті GNN може майже не навчитися впливу сусідів — це важливо перевіряти окремо; для підготовки до реального донавчання варто згодом додати сценарії з іншими K. Витрати вентиляції 0,5–2 м³/с на засік залишені за умовою, хоча вони надзвичайно великі для 300–2000 кг зерна.

Для повноцінної верифікації потрібно замінити умовні залежності на фізично обґрунтовані/виміряні, а потім порівняти прогноз із датчиками.
